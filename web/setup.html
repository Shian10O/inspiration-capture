手机收集入口

保留原来的 vivo 侧边栏入口。生成的授权仅可提交和补充，不能查看收藏或管理 Notion；可在下方单独撤销。

  1. 在这部手机打开本页，生成并下载配置文件。
  2. HTTP Shortcuts → 导入／导出 → 从文件导入，选择下载文件及“合并”。不要选择“替换”。
  3. 继续从原来的侧边栏启动「收下链接＋一句话」。看到「已上传到 Notion」才算完成。

同一文件重复合并会保留待上传队列，旧本地测试箱不会自动上传。若要生成另一份授权，请先处理旧授权下的待上传记录。配置文件含设备令牌，请勿转发；导入后可删除下载文件。

失败时显示「未上传／等待确认」，内容留在本机；在 HTTP Shortcuts 点「重试待上传灵感」。已有点点总结可复制后运行「补充点点总结」，粘贴之前收集的原笔记链接。

生成配置后会用公开模拟数据检查公网网关，在测试库保留一条可识别的测试记录；不读取私人收藏。
